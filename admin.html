개발자 로그인 (GitHub 토큰)

GitHub 토큰으로 직접 들어옵니다. 저장 대행 설정이나 고장 났을 때 쓰는 비상용입니다.

토큰 발급 방법 (처음 한 번만)

  1. GitHub 토큰 발급 페이지를 엽니다.
  2. Token name에 아무 이름이나 적습니다. (예: fox-ai-lab CMS)
  3. Expiration은 원하는 기간으로 정합니다. (기간이 지나면 다시 발급해야 합니다)
  4. Repository access → Only select repositories → fox-ai-lab 선택.
  5. Repository permissions → Contents 를 Read and write 로 변경.
  6. 맨 아래 Generate token → 나온 문자열을 복사해서 아래에 붙여넣습니다.

이 토큰은 이 저장소 하나만 수정할 수 있습니다. 공용 PC에서는 로그인하지 마세요.
